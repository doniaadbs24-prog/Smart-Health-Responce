Smart Health Response Application

Overview

Smart Health Response is a graduation project designed to help injured individuals request emergency assistance in the Jazan region of Saudi Arabia.

Key Features

* SOS Emergency Request: Allows users to send an emergency request quickly.
* GPS Location Sharing: Shares the user’s location to help responders locate them.
* Cloud Database: Uses Firebase Firestore to store and manage application data.
* Role-Based Access: Supports different roles for responders and healthcare facilities.

Technologies Used

* Flutter
* Dart
* Firebase Firestore
* GPS Location Services
